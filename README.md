# blender-material-teksturonos
Для разного вытащенного с помощью UmodelViewer-а. По имени материалов на моделях ищет соответствующие mat-файлы для получения из них диффузных текстур.  
От: [arbtttrn6](https://github.com/arbtttrn6) 

## Установка  

* Распаковать архив в папку настроек Blender'а (/blender/%Versija%/scripts/addons);
* В настройках Blender'а включить расширение.

## История  
* 14.02.2026 - Версия 1.0 (Blender 2.8);

## Использование  
Мой случай:  
Использовал [UEViewer](https://github.com/gildor2/UEViewer) от [gildor2](https://github.com/gildor2). Извлёк объекты: Они в итоге лежали в подпапках в UmodelExport. Симпортил некий объект или может сразу множество объектов в доступном формате (например gltf). Но довольно тяжело и муторно для каждой модели доставать текстуры.  
Это расширение для Blender'а требует лишь путь до папки UmodelExport. Материалы (в случае с gltf) на моделях берут названия из одноимённых mat-файлов в подпапках. Расширение ищет эти mat-файлы по названию материала на модели и получает из них параметр диффузной текстуры, устанавливая текстуру на модель.
